技术路线与引擎The layer after AlphaGenome: genome + environment + decision → next-generation traits.

AlphaFold 解开了蛋白质的结构，AlphaGenome 开始解读基因组的调控语言；下一块未被计算化的土地，是基因组如何在真实生命、真实环境里变成性状并传给下一代。我们从育种开始，把每一个世代变成一次可计算、可验证、可学习的实验。

我们不训练通用 DNA 模型。Evo 2、AlphaGenome、FarmGTEx 是我们的输入，不是对手。我们拥有的是它们都没有的标签：基因组 → 决策 → 真实生命 → 下一代结果。

引擎依据什么能测什么本站哪里能看到状态
E1 遗传引擎（冻结基准）ssGBLUP：y = Xb + Zu + e，u ~ N(0, Hσ²ₐ)；准确度上界 r² ≈ Nh² / (Nh² + Mₑ)（Daetwyler 2008）GEBV、可靠性；对照 BayesRDemo 1 的 A 臂与 r–N 曲线；Demo 3 的重训与逐头一致已实现
E2 功能先验引擎（挑战者）每个 SNP 的先验方差来自 Evo 2 嵌入、FarmGTEx eQTL / sQTL、保守性；进入 BayesRC / GFBLUP 类模型预期同群体 +1–5% 准确度；跨品系与小样本增益更大；不进主叙事Demo 1 的 G 臂（现为模拟先验）已实现 · 等真实先验文件
E3 世代模拟器（世代级世界模型）子代均值 = ½(GEBVₛ + GEBVₒ) + 显性 + G×E；子代方差由相位单倍型与重组图谱算出；配种受最优贡献选择约束（ΔF 上限）子代分布、配种方案Demo 1 的肉鸡式模拟器（多品系、场区、批次、真育种值）；Demo 3 的三代模拟模拟器已实现 · 子代方差与 OCS 待做
E4 G×E 引擎反应规范 / 多环境模型：性状 = 遗传 + 环境 + 交互按场区的育种值与选配建议Demo 1 的稳健门按场区 / 批次 / 品种分层；DSL 的环境协变量算子部分
E5 GenerationBench（裁判）模型冻结 → 预测加时间戳 → 配种 → 一个世代后揭榜；LR 法 ρ / μ / b、留品系与留世代验证、负对照零晋级、多重检验校正任何排序算法能否配得上下一代Demo 1 全部；Demo 4 换成留患者已实现
E6 智能体层（假设工厂）通用模型做编排、检索、报告；只能调用确定性工具（GRM、BLUP、LD、注释）；产出候选与假设，不产出数字假设生成变便宜后，验证带宽是否变成瓶颈的解Demo 0 智能体：回放一次真实闭环、你来当评审者；Demo 1 的 C / D 臂（遗传学家、构建者、评审者、分析师）；泄漏探针拦截已实现 · 离线 stub 与真实模型可切换
E7 执行层（湿实验自动化）建议直接进入基因分型实验室、表型采集与繁殖执行系统；自动化只动依从性、表型覆盖、标签回流延迟与（早选种或体外世代时）世代间隔，不动生物学的钟依从性、覆盖、延迟、验证带宽；十年累计进展的 what-if；提案放大后裁判的假阳性是否仍 ≤ αDemo 5 自驾育种（拖滑块）解析模型 · 等自动化报价与客户产能

验证带宽：产业以百万级计，实验室以千级计
