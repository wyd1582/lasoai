先说清楚"湿实验"在育种里指什么：基因分型实验室（提取、杂交、扫描）、表型采集（称重、图像、采食传感器）、繁殖执行（授精排程、孵化、胚胎移植）。人类线对应甲基化芯片、HLA 分型与免疫原性实验。自动化改变的是人的延迟和依从性，改不了生物学的钟：妊娠期和生长期不会因为机器人变短。
育种的人这样读：你最熟悉的三个痛点都在模型里：建议发出去只有一部分被执行（依从性）；不是每只动物都有表型回来（覆盖）；结果要等一个世代还要人工整理（延迟）。自动化把这三个数往 100%、100%、生物学最短时间推；世代间隔只有出雏即分型或体外世代技术才能动。
做 AI 的人这样读：N(t) = N0 + S·覆盖·max(0, t − 延迟)；r = 0.9·√(N h² / (N h² + Me))；ΔG = i·[c·r + (1 − c)·r0]；带宽 = S·覆盖 / 延迟；假阳性 = P·10·α（无裁判）对比 ≤ α（有裁判）。注意准确度在几千头参考群后就饱和了：自动化的价值不在"更准"，在更快、更全、更听话——以及在提案放大十倍后仍然不放假阳性。

4自动化能动的量：依从性、覆盖、延迟、世代间隔

自动化能动的四个量

依从性

建议被执行的比例。

Demo 3 里模拟器只有 1%，现实里几十%；建议直接进入繁殖执行系统后接近 100%。模型里不依从的配对按手工指数（r0）选。

表型覆盖

有表型回流的动物比例。

称重、图像、采食传感器让覆盖接近全体；覆盖决定每年进入参考群的样本数。

标签回流延迟

从选种到表型可用的年数。

手工整理让延迟超过一个世代；自动采集把它压到生物学最短时间。延迟直接除进验证带宽。

世代间隔

亲代出生到子代出生的年数。

只有出雏即分型（更早选种）或体外世代技术（牛：胚胎基因分型 + 体外受精）才动它；这是牛这条线最大的杠杆。

为什么自动化必须配裁判

想法越便宜，每年进裁判的候选越多。若每个候选只做一次 5% 显著性检验，白羽鸡 S2 情景十年会误放 {{d5.fp_no_s2}} 个假阳性进育种方案；裁判按试验数校正后，族错误率保持在 {{d5.alpha}} 以下——这正是 Demo 1 里负对照零晋级、Demo 0 里每一次拒绝的机制。自动化放大的是验证带宽，裁判决定这带宽变成结论还是变成噪声。

边界

生物学的钟不变

妊娠、孵化、生长期是硬下限；模型里延迟的最小值就是它。任何"自动化让世代更快"的说法，若不是靠早选种或体外世代技术，都不成立。

福利、监管、生物安全

模型里没有这些项；它们可能是真正的瓶颈。自动化配种与早期分型的合规路径要单独论证。

成本没有算

没有设备与人力成本项，所以本页不是投资回报表；拿到湿实验自动化的报价与客户产能后才能算。
