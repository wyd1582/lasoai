Accuracy versus reference size against the theoretical bound

The Daetwyler bound r = √(N·h² / (N·h² + Me)) depends on reference size N, heritability h² and the number of effective chromosome segments Me — hardly on model complexity. A measured curve above it has one explanation: leakage. It is a hard rule: exceed it and the run stops. Here h² = {{d1.h2}}, Me ≈ {{d1.me}}, largest excess {{d1.curve_max_excess}} (negative = never exceeded).

The deck says "cross-customer learning". The review table says: pooling reference populations within a line works; across lines and breeds the gain is small and may be negative. So it is tested in three tiers, and only tier 1 passing counts as support.

Low-density panel + imputation: accuracy by MAF

The solid-phase array strategy is "low density + imputation". On public pig data (5K / 20K panels, KNN imputation) overall concordance is about 0.70, only 0.58–0.67 for loci with MAF ≥ 0.2, and 5K ≈ 20K — KNN ignores local linkage, so this is a floor for the method, not a verdict on panel density. Real panels must be re-measured with Beagle / FImpute-type methods.

Commercial meaning

The judge is the product

Customers are not buying "a better model"; they are buying a validation no vendor can game: every method — theirs, ours — passes the same gates. That challengers rarely win supports the positioning.

The data are the asset

Every proposal, rejection and cost enters a permanent ledger; false positives the judge rejected are knowledge too. The longer the ledger, the better the next round's priors — the first compounding loop.

How to state promise two

The decomposition decides the wording: per trait, with intervals, and with the L term marked as a design assumption. "+50 %" or "+25 %" earns a place in external material only after a shadow run on real customer data.
