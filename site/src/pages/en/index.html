From pigs, chickens and cattle to dogs, cats and people: make every generation arrive sooner, with less disease and more healthy years. The method is to turn the largest biological experiment on Earth into a laboratory with a memory.

This site breaks the company's plan into six demos you can open: Demo 0 shows how the agents work, Demos 1–4 are the four things to prove, Demo 5 is the what-if of a fully automated loop. Each answers three questions: which sentence of the deck it proves, which product line it lands on, and what theory it rests on and what result would falsify it.

  • What the AI does inside it: four agent roles propose hypotheses, write code, find holes and debrief, and can only recommend; every change to the plan passes six deterministic gates. Replay one real loop →

Method: Read-out · Propose · Judge · Memory

Read-out, judge and memory share one set of assets; the agents only propose and change no state. every new value pool costs one new panel and one new batch of customers.

Read-out

Fixed panels: genotypes, methylation, HLA typing; the same measurements across pig, dog and human.

Propose

Four agent roles propose hypotheses, write code, find holes and debrief; they can only recommend, and the gates decide. Replay one →

Judge

One set of gates every prediction method must pass: forward validation, paired increments, negative controls, reproducibility.

Memory

An append-only ledger: every recommendation, every adoption, every outcome one generation later. Raw data belong to the customer; aggregates and models to the platform.

For breeders: Demo 3 is the selection workflow you already run — array batches, reference-population updates, breeding values, selection and mating advice, adoption, progeny outcomes — except that every step is recorded and traceable per animal. Demo 1 answers "is the AI actually more accurate than ssGBLUP?", and the answer comes from the judge, not from the vendor.
For AI people: frozen ssGBLUP is always the champion; any large model, deep net or functional prior is a challenger. Promotion requires a paired win on the same candidates and the same cutoff date, plus negative controls and multiple-testing correction. Demo 1 and Demo 4 are one judge applied to two fields.
For the board and investors: the four demos map onto five revenue lines: Demo 1/3 are the breeding agent and data platform (lines A, B, C), Demo 2 is cross-species read-out (line D), Demo 4 is audit and licensing (line E). Each page ends with "Commercial meaning": the number it wants to prove, how far it is proven, and what is still missing.

A closed-loop breeding-decision platform

Cross-customer data custody and decisions for pigs, chickens and cattle; gain-sharing contracts; validation bandwidth ≥ 3 million samples per year. Benchmark: Neogen genomics + Genus royalties.

The cross-species read-out layer

The default memory of life data
