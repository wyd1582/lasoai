拿到之后会发生什么

页面自动变真

每个 Demo 的构建脚本只认输入文件；换成真实数据后，RUN.json、图、CLAIMS 和本站的每个数字自动更新，"内部预测版"徽章由构建脚本撤下。

可以说的话会变

每个 Demo 的"可以说 / 不能说 / 需要什么数据"由脚本按数字生成；真实数据到位后，右栏的条目逐条移到左栏，或者被证伪后留在中栏——两种结果都写进 CLAIMS。

止损线是事先写好的

负对照晋级 → 方法作废；功能先验增益 < 1% → 只留科研合作；留物种 r < 0.8 → 单物种时钟；稀有 HLA 等位基因不足 → 筛查 + 测序确认。数据决定走哪条路，不由我们的偏好决定。

三个要一号位决定的事（PRD §6）

  1. 白羽鸡客户的读出产品是否承诺甲基化。鸟类需要单独面板，建议先不承诺；先做基因型与台账。
  2. 承诺二的措辞：+50% 还是 +25%。Demo 1b 的分解表说：个体不可测的性状只改 r 已够 50%，个体可测的性状需要 r 与 L 一起；建议按性状分开，等第 1 行数据的影子运行再定数字。
  3. 中国人群 HLA 参考面板从哪来。这决定人类线楔子的可行性（第 6 行）。
