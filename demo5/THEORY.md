# Demo 5 · THEORY（依据、极限、可证伪点）

本 demo 不是模拟器实验，而是把湿实验自动化能改变的四个量代入两条已知公式的**解析模型**。它回答"如果……会怎样"，不回答"现在是多少"。

## 依据

| 量 | 公式 | 依据 |
|---|---|---|
| 每世代进展 | ΔG = i·r·σA（每年 ÷ L） | 育种者方程（Falconer & Mackay 1996；Schaeffer 2006 对奶牛基因组选择的推演） |
| 准确度 | r = k·√(N h² / (N h² + Me))，k = 0.9 | Daetwyler et al. 2008；Goddard 2009；k 是现实折扣（非加性、G×E、模型误设） |
| 依从性 | ΔG = i·[c·r + (1 − c)·r0]·σA | 不依从的配对按现行手工指数（准确度 r0）选：混合选择 |
| 参考群 | N(t) = N0 + S·覆盖·max(0, t − 延迟) | 标签回流延迟决定何时能进参考群（GenoFrame 的 available_at 约定） |
| 验证带宽 | S·覆盖 / 延迟 | PRD §0：bandwidth = samples_per_year / label_latency_years |
| 假阳性 | 无裁判 P·10·α；有裁判 ≤ α | 单次检验 vs 族错误率控制（Bonferroni / DSR 式扣减，Demo 1 研究门） |
| 世代间隔 | 只在出雏即分型或体外世代时变 | Schaeffer 2006（奶牛 L 从 ~6 到 ~2 年）；体外胚胎技术文献 |

## 极限

- 准确度在几千头参考群后饱和（Me 小的纯系尤其如此）：自动化的价值不在"更准"。
- 模型没有近交约束（ΔF）、没有成本、没有福利与监管；四个量之间也没有交互项。
- 假阳性用最简单的口径（每候选一次 5% 检验）；真实的裁判还有配对增量与稳健门，会更严。

## 可证伪点

1. 一家客户的繁殖执行记录显示依从性已经接近 100% → 自动化在依从性上没有增量，价值只剩延迟与覆盖。
2. 传感器覆盖后标签延迟没有下降（瓶颈在生物学而非整理）→ 带宽增量比模型小。
3. 提案放大后裁判的假阳性没有保持在 α 以下 → 裁判失效，先修裁判（与 Demo 1 同一条止损线）。
